# TrackFlow capstone handoff

This folder contains the production-ready plan for the final five-minute video.
It is intentionally a recording package, not a replacement for the required
human presentation.

## Files

- `PITCH.md` — timed product narrative and camera/screen cues.
- `DEMO_RUNBOOK.md` — cold-start, demo data, fallback, and rehearsal steps.
- `RECORDING_CHECKLIST.md` — acceptance criteria and final packaging checklist.
- `QA_WORKSHEET.md` — the three exact personal questions with answer prompts.
- `TrackFlow-description.txt` — ready 1–2 sentence project description; rename
  it to match the final MP4 basename.

## Human-only completion gates

1. Replace `[YOUR NAME]` in the pitch and supply truthful personal Q&A answers.
2. Practice aloud twice, then record landscape with the speaker visible.
3. Export `FirstnameLastname-TrackFlow.mp4` at 1080p if possible.
4. Choose/sign the media release or create the explicit cohort-private opt-out.
5. Upload the three required files to one permanent shared folder, test it in a
   private browser, and add that permanent link to the root README and LMS.

Do not put the MP4, signed release, credentials, or private share tokens in Git.
