All five mandatory events were observed end to end. The same sessionId
followed the whole browser session and the userId was the HMAC pseudonym,
never the account id or email.

Not observable in this run: `page_load_recorded`. The automated browser
pane loads its tab hidden (document.visibilityState === "hidden" from
t=0) and Chromium does not report LCP for hidden documents, so the Web
Vitals hook had nothing to forward. It is covered by the hook's unit path
and fires in a normal foreground tab.

Defect found and fixed during this run: under the default configuration
the browser resolved the telemetry endpoint to "" (it read the raw
NEXT_PUBLIC_API_BASE_URL instead of the resolved API base) and silently
discarded every batch. resolveTelemetryEndpoint now falls back to the
same API_BASE_URL the rest of the app uses; regression test added.
