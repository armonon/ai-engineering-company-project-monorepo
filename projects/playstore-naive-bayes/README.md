# Google Play review classifier — Naive Bayes

This project completes the 4Geeks **Naive Bayes sentiment-classification**
assignment with the official `playstore_reviews.csv` dataset. It keeps text
vectorisation inside each model pipeline, compares all three required Naive
Bayes implementations, tunes the best family without touching the held-out
test set, evaluates two alternative model families, and saves a complete
reproducible inference pipeline.

## Rubric coverage

1. **Load and understand the data** — validates the official three-column
   schema, nulls, binary target, duplicates, and class balance.
2. **Process text** — trims and lowercases reviews, removes the non-predictive
   package name, and keeps `CountVectorizer` inside the fitted pipeline.
3. **Train all Naive Bayes variants** — compares `GaussianNB`,
   `MultinomialNB`, and `BernoulliNB` on the same validation split.
4. **Optimise without leakage** — a stratified five-fold grid search runs only
   on the development partition; the test split is evaluated once at the end.
5. **Save the model** — the validation-selected Random Forest pipeline is
   saved to `models/playstore_sentiment.joblib`; the tuned MultinomialNB
   pipeline is preserved separately as `models/multinomial_naive_bayes.joblib`.
6. **Explore alternatives** — balanced Random Forest and Logistic Regression
   baselines are included in the validation comparison and decision record.

## Run

```bash
cd projects/playstore-naive-bayes
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/train.py
.venv/bin/python scripts/build_notebook.py
.venv/bin/pytest -q
```

The notebook at `src/explore.ipynb` is an executed, reviewer-friendly summary.
Model weights are small and versioned here because this model is the student's
own fitted course artifact, not a downloaded third-party foundation model.

## Design decision

Multinomial Naive Bayes is the natural Naive Bayes model for non-negative token
counts. Gaussian Naive Bayes must densify the matrix and assumes continuous
Gaussian features; Bernoulli Naive Bayes discards word frequency. The Random
Forest alternative produced the strongest validation F1, so it was selected
without consulting the test set and refitted on the full development split.
Both final pipelines are saved so a reviewer can inspect the required Naive
Bayes solution and the assignment's stronger alternative independently.
