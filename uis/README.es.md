# Carpeta `uis`

Esta carpeta contiene **todos los proyectos con interfaz de usuario** del proyecto transversal de AI Engineering de TrackFlow — por ejemplo: un sitio web público, un panel de administración, portales internos u otras herramientas sólo-frontend.

Los proyectos que se almacenan aquí son:

- **`public-website`** — el sitio web público del Milestone 1 (HTML estático + Tailwind + `validation.js`), construido a partir del briefing oficial.
- **`website`** — el sitio Next.js del producto de cotización de envíos.
- **`backoffice`** — la aplicación interna de administración: autenticación, inventario, incidencias, RFP, chat de CX, observabilidad de agentes, telemetría, talento y proveedores.
- **`talent-pipeline-tracker`** — el flujo de selección entregado como milestone estable y mantenido dentro del mismo grafo de workspaces.

Organiza `uis/` por **responsabilidades distintas**: cada subcarpeta cubre un área diferente de la empresa (por ejemplo, web pública frente a operaciones internas) e incluye su propia documentación técnica y funcional.
