# TrackFlow public website — Milestone 1

This static Tailwind CSS site carries the TrackFlow public-company work into the monorepo. It reflects the official Milestone 1 context: warehouse management, last-mile delivery, and reverse logistics in Mexico and Spain, plus a validated lead form for the Commercial team.

Run it from the repository root:

```bash
npx serve uis/website
```

Then open the local URL printed by `serve`.
